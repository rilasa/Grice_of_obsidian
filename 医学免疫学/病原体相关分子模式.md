# 概念
**病原体相关分子模式**（pathogen-associated molecular pattern,PAMP），又称外源性危险分子，是指某些病原体或其产物所共有的高度保守且对病原体生存和致病性不可或缺的特定分子结构。
# 主要包括
病原体独有或富含的核酸、蛋白\脂类和多糖分子,如G-菌脂多糖和鞭毛蛋白，G+菌脂磷壁酸和肽聚糖，病原体表面甘露糖、岩藻糖或酵母多糖，病毒双链RNA和单链RNA，细菌和病毒非甲基化CpG DNA基序等。
# 介导效应
病原体或其他产物通过PAMP与固有免疫细胞或其他组织细胞表达的相应模式识别受体结合可启动固有免疫应答。
