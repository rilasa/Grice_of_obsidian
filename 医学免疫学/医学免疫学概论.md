# 免疫系统的组成
## ==免疫器官和组织==
### 中枢免疫器官
#### 骨髓（Bone marrow）
1. 结构：
	1. 分为黄骨髓和红骨髓。成年人红骨髓和黄骨髓各50%。
	2. 黄骨髓：长骨干的髓腔中，含有脂肪组织，可以转化为红骨髓
	3. 红骨髓：位于长骨、扁骨、不规则骨头的骨骺端的松质骨，有活跃的造血功能。
	4. MIH：造血微环境。由基质细胞及其分泌的多种造血生长因子，以及细胞质基质组成。
2. 功能:
	1. 是各种血细胞（多种免疫细胞）的发源地
	2. 是B淋巴细胞分化、发育成熟的场所
	3. 再次免疫应答抗体产生的场所
#### 胸腺 (Thymus)
1. 结构
	1. 分为实质和髓质
	2. 有生理性萎缩
	3. DiGeorge综合症：先天性胸腺缺陷
2. 功能
	1. 是T淋巴细胞分化、发育成熟的场所
	2. T淋巴细胞自身耐受的建立与维持
	3. 免疫调节
### 外周免疫器官
#### 淋巴结 (lymph node)
1. 结构
	1. 分为皮质和髓质
	2. 浅层皮质区：
		1. 初级淋巴滤泡：富含B淋巴细胞 
		2. 次级淋巴滤泡：生发中心
	3. 深层皮质区：富含T淋巴细胞
	4. 髓质：
		1. 髓索：富含B淋巴细胞和浆细胞
		2. 髓窦：富含巨噬细胞
2. 功能
	1. 成熟T、B淋巴细胞定居的主要场所（T cell 75%   B cell 25%）
	2. 适应性免疫应答发生的关键部位
	3. 淋巴细胞再循环
	4. 过滤作用
#### 脾 (spleen)
1. 结构
	1. 胚胎时期的造血器官
	2. 结构上分为红髓和白髓
	3. 白髓是淋巴细胞的主要场所
	4. 边缘区和红髓中含有大量巨噬细胞
2. 功能
	1. 成熟T、B淋巴细胞定居的主要场所（B cell 60%  T cell 40%）
	2. 免疫应答的场所
	3.  合成补体等
	4. 过滤作用
#### 黏膜相关淋巴组织（HALT）
> 是发生黏膜应答的主要场所
1. 结构
	1. GALT（肠相关淋巴组织）
	2. NALT（鼻相关淋巴组织）
	3. BALT（支气管相关淋巴组织）
2. 功能
	1. 通过局部黏膜应答，产生分泌型Ig A，发挥保护作用
	2. GALT参与肠黏膜的稳态

## 免疫分子
### 膜型
#### 白细胞分化抗原
在造血干细胞向谱系分化的不同阶段以及向各类白细胞成熟活化的不同过程中，细胞表面表达的标记分子被称为**人白细胞分化抗原**（HLDA）
#### 免疫细胞表达的膜型配体和受体

#### 黏附因子     
介导细胞间或细胞与细胞外基质间相互结合和作用的分子
#### 主要组织相容性复合体分子
1. 在器官移植中决定组织是否相容的免疫分子
2. 识别和提呈抗原肽，参与T细胞发育、分化、活化，参与免疫及炎症调控
### 分泌型
#### 细胞因子
1. 作用方式
	1. 自分泌：分泌后
	2. 旁分泌
	3. 内分泌
2. 主要分类
	1. 干扰素
	2. 白细胞介素
	3. 肿瘤坏死因子
	4. 集落刺激因子
	5. 生长因子
	6. 趋化因子
#### 抗体

#### 补体
1. 存在于血清、组织液和细胞表面，由多种蛋白质组成的反应系统
2. 固有免疫防御系统的重要组成部分
3. 活化过程表现为一系列的级联酶解反应并受到精密的调控
