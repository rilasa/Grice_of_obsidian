# 定义
细胞因子是由免疫细胞和组织细胞分泌的在细胞间发挥互相调控作用的一类小分子可溶性蛋白质，通过结合**相应受体**调节细胞生长分化和效应，调控免疫应答，在一定条件下也参与炎症等疾病的发生
# 细胞因子的基本特征
1. 小分子可溶性蛋白质，多为糖蛋白，MW：8-30kDa
2. 微量高效性：pM
3. 通过结合细胞表面相应受体发挥生物学活性
4. 可诱导产生，合成具有自限性
5. 半寿期短
6. 多为近距离发挥作用
# 细胞因子的功能特点
1. 多效性
2. 重叠性
3. 协同性
4. 拮抗性
5. 网络性
# 细胞因子的分类
1. [[白细胞介素]] (interleukin ,**IL**)
2. [[集落刺激因子]] (colony stimulating factor ,**CSF**)
3. [[干扰素]] （interferon,**IFN**）
4. [[肿瘤坏死因子]] (tumor necrosis factor,**TNF**)
5. [[趋化因子]] (chemokine)
6. [[生长因子]]（growth factor, **GF**）
