# 细胞膜的结构和化学组成
## 细胞膜的结构
**流动镶嵌模型**(fluid mosaic model)：Singer 和 Nicholson
## 化学组成和分子结构
### 脂类：20% - 40%
磷脂>70%；胆固醇<30%；少量糖脂<10%
#### 磷脂
- 磷脂分子：甘油分子的羟基分别与脂肪酸和磷酸及碱基相结合
- 脂质双层是由脂质分子本身的理化性质决定的
分子组成：
- 磷脂酰胆碱
- 磷脂酰丝氨酸
- 磷脂酰乙醇胺
- 磷脂酰肌醇
### 蛋白质：60% - 80%
- 整合蛋白：20%-30%，主要附着细胞膜内表面，与脂质极性基团或膜中的整合蛋白相结合。如红细广胞膜内表面的骨架蛋白。
- 表面蛋白：70%-80%，肽链一次或多次穿膜。包括受体蛋白、转运蛋白等，主要完成物质转运、信-号转导等。
### 糖类：5%
作用：
- 细胞天线、信号识别
- 糖类带有负电荷，使细胞表面呈现负电荷
- 可作为分子标记发挥受体或抗原的功能
# 细胞膜的物质转运功能
**细胞膜**是细胞与周围环境之间的屏障，可使膜两侧物质有选择的交流，完成物质跨膜转运。物质跨膜转运也是物质代谢、能量代谢的基础。
