# 生理学概述
## 什么是生理学
定义：生理学是研究人体**正常**生命活动现象及其**功能**活动规律的科学
## 生理学的研究水平
- 整体水平
- 系统水平
- 器官水平
- 组织水平
- 细胞水平
## 生理学的指导思想
1. **稳态**（homeostatsis）
2. **整合**（integration）
## 生理学的研究方法
- 在体（in vivo）
- 离体（in vitro）
+ 动物实验
+ 人体实验

# 生命活动的基本特征
## 新陈代谢(metabolism)
## ==兴奋性(excitability)==
-  兴奋：接受刺激产生生物电反应过程及表现
- **兴奋性**：机体对**刺激**发生**反应**的能力
	- 兴奋性的本质是动作电位的**产生**
1. **刺激(stimulus)**：能为机体感受的**内、外刺激的变化**
	1. 物理性刺激：热刺激、电刺激、光刺激、声刺激
	2. 化学性刺激
	3. 生物性刺激
	4. 社会性刺激：应激，精神活动，应激性溃疡
2. **反应(response)**：接受刺激后，机体发生活动状态的改变
	1. 兴奋：静止 -> 活动  or  活动↑
	2. 抑制：活动 -> 静止  or  活动↓

# 机体机能的调节
## 内环境与稳态
## 内环境
1. 概念：体内各种组织细胞直接接触并赖以生存的环境
2. 组成：
	1. 体液约占体重的60%
	2. 细胞内液占体液的**60%**
		1. 血浆（**5%**）
		2. 组织液（**15%**）
	3. 细胞外液占体液的**40%**
3. 作用：
	1. 提供稳定的理化条件
	2. 提供稳定的营养物质并带走代谢废物
## 稳态（Cannon提出）
1. 定义：内环境中的理化性质相对稳定的状态
2. 特点：动态平衡
3. 范围：细胞 -> 组织 -> 器官 -> 系统 -> 整体
4. 举例：血压、酸碱平衡、体温
## 机体功能的调节方式
- 神经调节
	1. 定义：**神经系统**参与，通过**神经反射活动**从而调节机体生理活动的方式
	2. 反射的定义：机体在中枢系统的参与下对内外环境的刺激做出的规律性应答，是神经调节的基本形式
	3. 分类：条件反射、非条件反射
	4. **特点：迅速，调节精确，持续时间短**
	5. 举例：人们看到食物或进食时，引发的反射性唾液分泌的过程
- 体液调节
	1. 定义： 体内产生的某种**化学物质**，通过**体液途径**到达并作用于靶细胞并影响其生理活动的一种调节方式
	2. 作用途径：内分泌，旁分泌，神经内分泌
	3. **特点：缓慢，持久，广泛**
	4. 举例：胰岛α细胞分泌的胰高血糖素刺激胰岛β细胞分泌胰岛素
- 自身调节
	1. 定义：组织、细胞**不依赖神经或体液调节**而产生的**适应性反应**
	2. 特点：局限（范围和广度）
	3. 举例：肾小球入球小动脉内压力增高，牵张入球小动脉平滑肌，触发其收缩，使入球小动脉管径变小，阻力增加，从而维持肾血流量和肾小球滤过率的相对稳定
# 功能自动控制系统
## 反馈控制系统(feedback)
1. 定义：控制系统通过**控制信息**作用于受控系统，受控系统通过**反馈系统**影响控制系统的活动
```mermaid
graph LR
	A[控制系统] -- 控制信息 --> B[受控系统]
	B -- 受控信息 --> A
```
2. 分类：
	1. **负反馈**
		1. 定义：反馈信号的作用是减低控制部分的活动，使效应器活动方向于原活动方向相反
		2. 作用：**维持稳态**
		3. 缺点：滞后、波动
		4. 举例：血压、体温的维持
	2. **正反馈**
		1. 定义：反馈的作用是加强控制部分的活动，是效应器活动方向与原方向相同
		2. 作用：**加快生理活动的完成**
		3. 举例：血小板聚集、排尿、钠通道开放
```mermaid
	graph LR
			A[控制部分] -- 控制/生理信息 --> B[效应器]
			B -- 反馈信息 --> A
```


3. 前馈控制
	1. 概念：在控制信息到来之前，机体受到来自其他信息（前馈信号）的提前干预，并对效应器进行调控
	2. 特点：提早干预
```mermaid
graph LR
	A[前馈信息] --> B[控制部分]
	B -- 控制/生理信息 --> C[效应器]
	C -- 反馈信息 --> B
```
