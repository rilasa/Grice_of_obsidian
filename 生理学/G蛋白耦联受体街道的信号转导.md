# 转导顺序
配体 -> 受体 -> G蛋白 -> 效应酶 -> 第二信使 -> 蛋白激酶 -> 细胞反应
# 过程
![[Pasted image 20260928110636.png]]
- 配体结合受体(receptor)，使G蛋白激活，G蛋白的$\beta\text{和} \gamma$ 亚单位脱落，$\alpha$ 亚单位上结合的GDP变为GTP，结合了GTP的$\alpha$亚单位就是激活了的G蛋白
- 激活了的G蛋白激活腺苷酸环化酶（AC），使ATP转化为cAMP，cAMP就是第二信使。
- cAMP激活下游的蛋白激酶，使蛋白质磷酸化，使蛋白质功能变化
